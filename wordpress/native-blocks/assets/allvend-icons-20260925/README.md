# ALLVEND pictograms (2026-09-25)

Nine brand-neutral, single-color blue (`#0B63F6`) outline icons for the nine ALLVEND feature cards. Each PNG is 96 × 96 pixels with a transparent background. The matching SVG files are editable vector sources; `contact-sheet.png` is a visual QA aid, not a website asset.

| Feature | File |
| --- | --- |
| Оплата услуг | `payment-services.png` |
| Самообслуживание | `self-service.png` |
| Трансляция рекламы | `advertising-video.png` |
| Безналичная оплата | `cashless-pos.png` |
| Считывание QR | `qr-scan.png` |
| Биометрическая идентификация | `biometric.png` |
| Настройка интерфейса | `interface-settings.png` |
| Удалённое управление | `remote-console.png` |
| Продажа товаров | `goods-sales.png` |

Regenerate with `node wordpress/native-blocks/assets/allvend-icons-20260925/build-icons.mjs` from the repository root. Eight paths use the already installed [Lucide](https://lucide.dev/) icon set (ISC license); the handheld POS path is drawn in the same style in the build script. No third-party brand marks are included.
