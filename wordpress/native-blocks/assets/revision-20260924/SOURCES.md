# Источники изображений FastSYS

- `fastsys-boot-official-source.png` — исходный встроенный кадр `Im9.png` из [официальной инструкции по настройке ПО ALLVEND](https://ftp.isg.dev/docs/instruction_setup_and_service_mode_allvend.pdf), стр. 4 из 26, редакция от 14.07.2021. Это полный скриншот рабочего стола автора с окном загрузки FastSYS 5; содержимое сохранено без изменений.
- `fastsys-boot-official-20260924.webp` — только чёрная область экрана загрузки из того же кадра: прямоугольное кадрирование и сжатие в WebP, без дорисованных элементов. Воспроизводится скриптом `../../optimize-fastsys-boot-20260924.mjs`.

[Официальная страница FastSYS](https://www.isg.dev/ru/products/fastsys/) подтверждает работу с flash-накопителя, систему бинарных обновлений и пять степеней криптозащиты. Страница не подтверждает обещание бесперебойной работы каждого устройства «на протяжении десятилетий».

## Баннер финансовых условий и пиктограммы

- `banner-finance-terminal-source.png` — изображение, созданное ИИ на основе предыдущего баннера SkySend: POS-устройство заменено напольным платёжным терминалом, удалены непроверенные проценты и надписи. Это иллюстрация, не фотография конкретной модели устройства.
- `banner-finance-terminal-20260924.webp` — уменьшенная до 1440 px WebP-версия для сайта (23,2 КБ).
- `icons/payment-kiosk-20260924.png` и `icons/zip-20260924.png` — пиктограммы, созданные кодом в `build-feature-icons-20260924.mjs`; первая показывает напольный терминал, вторая тип файла ZIP.
