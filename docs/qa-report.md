# SkySend: проверка и согласование

Дата проверки: 9 сентября 2026 года.

## Развёрнутая конфигурация

- WordPress 7.1, русская локализация;
- Apache 2.4.66;
- PHP 8.5.4;
- MariaDB 11.8.6;
- кастомная одностраничная тема `SkySend 2.0.0`;
- временный адрес стенда: `http://31.129.98.28/`.

Старый статический сайт в jail `/srv/jails/www` сохранён для отката. Его служба
отключена, запросы принимает Apache с новой WordPress-установкой.

## Проверка требований ТЗ

- На первом экране три слайда: «Более 5000 поставщиков услуг», «Лучшие
  финансовые условия», «ПО ALLVEND».
- Под баннером расположен обновлённый блок решений с единым набором плоских
  пиктограмм; пункт «Торговым сетям» заменён на «Рекламодателям».
- Новости, «Скачать», «Купить», «Автопробег» и отдельный раздел «Партнёрам»
  удалены.
- Преимущества вынесены на главную страницу и дополнены раскрывающимися
  пояснениями. «Круглосуточная поддержка» удалена.
- В «Программах» основным продуктом указан ALLVEND. FINGER и ПО для POS-терминала
  удалены.
- «О системе» заменён на «Контакты»: подключение, поддержка, телефон
  `+7 (861) 201-12-21` и Telegram `@infsysgroup`.
- Онлайн-чат, социальные сети и ссылка `www.isg.dev` отсутствуют.
- Внизу оставлена только компактная строка копирайта и контактов.
- Карточки и элементы интерфейса выполнены без теней, в единой плоской стилистике.

## Найденные и исправленные ошибки

1. В конфигурации Apache была несовместимая комбинация директивы `Options`.
   Исправлена на явные `+FollowSymLinks -Indexes`, проверка конфигурации проходит.
2. Ограничения виртуальной машины не позволяли PHP выделить память для PCRE JIT,
   из-за чего журнал наполнялся предупреждениями. Для Apache отключён `pcre.jit`;
   повторные запросы выполняются без записей в журнале ошибок.
3. Первый заголовок баннера приведён к точной формулировке ТЗ «Более 5000
   провайдеров услуг».
4. Старый сайт не имел полного набора метаданных нового лендинга. Добавлены
   canonical, Open Graph, robots meta и структурированные данные Organization.
5. Автопрокрутка баннера отключается при системном ограничении анимации;
   доступны клавиатурное управление и нумерованные переключатели слайдов.
6. Удалены добавленные при редизайне рекламные слоганы и неподтверждённые
   интерпретации. Тексты главной страницы и страниц партнёров приведены к
   сведениям исходного сайта SkySend.
7. WordPress формировал корректный XML sitemap, но отвечал для него кодом 404.
   Статус исправлен на HTTP 200 и повторно проверен.
8. Орбитальная схема на страницах партнёров не объясняла связь центральной
   пиктограммы с подписями. Она заменена на плоский информационный блок с
   названием раздела и тремя последовательно подписанными пунктами.
9. Проведена ревизия остальных смысловых схем: круговая карта возможностей на
   страницах партнёров заменена озаглавленным нумерованным списком, «мишени» в
   преимуществах — карточками «Ключевой факт», а из карточек партнёров удалены
   декоративные линии и узлы, похожие на неподписанную диаграмму.

- Главный экран, категории партнёров и перечень программ:
  `https://skysend.ru/`.
- ПО ALLVEND: `https://skysend.ru/allvend.html`.

  `benefits/lower-costs.html`, `benefits/stable-job.html`,
  `benefits/exclusive-innovations.html`, `benefits/the-high-speed.html` и
  `benefits/protection-of-data.html` старого сайта.
- РМА Windows/Linux, РМА Android и XML-шлюз: страницы `program/rma-pc.html`,
  `program/rma-android.html` и `program/xml-gateway.html`.
- Материалы для партнёров: исходные страницы разделов платёжных агентов,
  провайдеров услуг, поставщиков товаров, рекламодателей, представителей и
  шлюзовиков.

Из исходных материалов сознательно не перенесены сведения, исключённые
последующими требованиями: офисный адрес, круглосуточная поддержка, FINGER,
ПО для POS-терминала, старый номер 8-800, новости, разделы покупки и загрузок.

## До переключения домена

Сейчас `skysend.ru` и `www.skysend.ru` указывают на прежний адрес
`89.208.38.114`. Для публикации на домене требуется:

1. Получить итоговое согласование Игнатьева по стенду.
2. Направить обе A-записи на `31.129.98.28`.
3. После обновления DNS выпустить TLS-сертификат для обоих имён.
4. Заменить WordPress `home` и `siteurl` на `https://skysend.ru`, затем повторно
   проверить canonical, sitemap, вход в панель и внешнюю доступность.
