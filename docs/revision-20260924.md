# SkySend — правки от 24.09.2026, часть 2

Изменения опубликованы только на тестовой ВМ `31.129.98.28`. Компания переносит
их в jail `www` отдельным полным пакетом WordPress; на сервере компании этот
набор не применялся. Страница, шапка, футер и стили остаются редактируемыми в
стандартном редакторе WordPress. Для автопрокрутки используется уже установленный
Carousel Slider Block; нового плагина не добавлено.

## Выполнено

- Телефон выведен из меню в правую группу шапки рядом с входом.
- Кнопки и категории провайдеров получили одинаковое светло-голубое состояние
  наведения. Правило находится в Global Styles WordPress, потому что штатный
  блок Tabs не имеет настройки hover в интерфейсе.
- Три баннера переведены в оптимизированный WebP: вместе 222 КБ вместо 2,50 МБ.
- В каждой из шести карточек партнёров есть изображение, пиктограмма PDF, ссылка,
  размер и год архивного документа. Добавлено предупреждение об устаревших
  условиях. «Внедрение систем самообслуживания» исправлено.
- Сгенерирован и установлен новый favicon 512×512 на основе логотипа SkySend.
- Внешние HTTP(S)-ссылки открываются в отдельной вкладке с `noopener noreferrer`;
  якоря страницы, телефон и почта остались в текущей вкладке.
- ALLVEND: официальный скрин ПО слева, справа новый заголовок, описание и девять
  функций с пиктограммами/брендами из запроса. Отображение сделано стандартными
  блоками Image, Columns и Group.
- Скорость: иллюстрация кластера без цифр слева, справа преимущества круглым
  списком, C/C++ и итоговая фраза.
- Заменено изображение шлюзовика без крупной надписи XML, чтобы не возвращать
  замечание предыдущей итерации.

## Источники и ограничения

- Скриншот и функции ALLVEND: [официальная страница](https://www.isg.dev/ru/products/allvend/).
- Технические сведения SkySend, включая C/C++: [официальное описание процессинга](https://ftp.isg.dev/docs/description_processing_skysend.pdf).
- Шесть архивных PDF, прямые ссылки, даты и размеры:
  [реестр вложений](../wordpress/native-blocks/assets/revision-20260924/offers/README.md).
- Источники брендовых знаков и оговорка о товарных знаках:
  [SOURCES.md](../wordpress/native-blocks/assets/revision-20260924/icons/SOURCES.md).

PDF относятся к 2015–2021 годам и не подтверждают действующие коммерческие
условия. Для торговых сетей доступен старый документ о размещении терминалов,
а не о новом внедрении систем самообслуживания; это отражено ссылкой «архивный
документ». Брендовые пиктограммы следует согласовать с правообладателями при
публичном использовании, если они подразумевают партнёрство.

- Главная, шесть PDF, новый favicon и 98 локальных изображений/srcset прошли

**База изменилась.** Одной заменой файлов на уже работающем стенде правки не
появятся: HTML блоков и favicon-опция хранятся в БД, изображения/PDF — в
`wp-content/uploads`. Полный архив восстанавливать в отдельный каталог и
пустую БД по вложенной инструкции. Не импортировать `database.sql` поверх
существующих таблиц и не распаковывать весь пакет в webroot.
