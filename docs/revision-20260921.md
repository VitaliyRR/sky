# Правки SkySend от 21.09.2026

Правки выполнены для действующей страницы на стандартных блоках WordPress и
сохранены в воспроизводимых исходниках репозитория. Публикация выполняется
одноразовой проверяемой миграцией: она начинает работу со свежего WXR-экспорта,
проверяет контрольную сумму страницы и отказывается перезаписывать более новые
изменения редактора.

## Изменения

- минимальная высота баннера уменьшена с 600 до 500 px, вертикальные отступы
  сокращены;
- три кнопки «Подробнее» в баннере смещены вниз адаптивным отступом;
- финансовый баннер показывает платёжный терминал, мешок «ДОХОД» и `+20%`;
- баннер ALLVEND собран в одну картинку по присланной схеме: логотип в центре,
  четыре типа устройств соединены с единым программным обеспечением;
- текст ALLVEND заменён на «ALLVEND — единое ПО для разных типов устройств
  самообслуживания.»;
- видимый заголовок «Партнерам» удалён;
- «Поставщикам товаров» заменено на «Ресторанам быстрого питания», добавлена
  фотография посетителя у киоска McDonald’s, подпись сокращена до
  «Автоматизация клиентского обслуживания»;
- для торговых сетей установлена подпись «Внедрение самообслуживания»;
- в карточку шлюзов возвращено исходное изображение со знаком XML;
- показатели заменены на согласованные формулировки: «20 лет +» / «Работаем с
  2006 года», «Поставщиков и партнеров», «Оборот системы, Р», «Проведено
  транзакций».

## Изображения

Финальные файлы проекта:

- `wordpress/wp-content/themes/skysend/assets/images/banner-finance-20260921.png`;
- `wordpress/wp-content/themes/skysend/assets/images/banner-allvend-diagram-20260921.png`;
- `wordpress/wp-content/themes/skysend/assets/images/partner-fast-food-20260921.jpg`;
- существующий исходник `partner-gateways.jpg` со знаком XML.

Новые растровые изображения созданы встроенным `image_gen`; CLI/API-режим не
использовался. Исходные PNG баннеров имеют размер 1774 × 887. Фото карточки
сохранено в JPEG с качеством 88 для уменьшения веса.

### Финансовый баннер

```text
Use case: precise-object-edit
Asset type: SkySend homepage finance carousel illustration
Input images: текущий финансовый баннер — edit target и референс стиля.
Primary request: заменить правую композицию на узнаваемый платёжный терминал,
мешок с точной надписью «ДОХОД» и отдельный знак «+20%».
Composition: исходный холст 2:1; левые 48% полностью свободны для HTML-текста.
Style: плоская редакционная иллюстрация; #edf4ff, #0b63f6, #071426, белый.
Constraints: «ДОХОД» и «+20%» по одному разу, без другого текста, брендов,
графиков, водяных знаков, градиентов и 3D.
```

### Баннер ALLVEND

```text
Use case: compositing
Asset type: SkySend homepage ALLVEND carousel illustration
Input images: схема заказчика — референс композиции; предыдущий баннер — референс
палитры и устройств; allvend-logo.png — источник фирменного логотипа.
Primary request: одна иллюстрация справа — логотип ALLVEND в центральном белом
шестиугольнике, соединённом с платёжным терминалом, настольным киоском,
информационной панелью и парковочным/платёжным киоском.
Composition: холст 2:1; левые 48% свободны для HTML-текста.
Constraints: один встроенный логотип, четыре устройства, без другого текста,
лишних объектов, водяных знаков, градиентов и 3D.
```

## Публикация

1. Импортировать только четыре изображения новой редакции:

   ```bash
   sudo wp eval-file wordpress/native-blocks/import.php revision-media-20260921 \
     --path=/var/www/skysend --allow-root
   ```

2. Получить свежий WXR-экспорт страницы №67 и собрать изменение сериализаторами
   установленной версии WordPress и Carousel Slider Block:

   ```bash
   SKYSEND_JSDOM=/path/to/jsdom SKYSEND_ORIGIN=http://31.129.98.28 \
     node wordpress/native-blocks/build.mjs --revision-20260921 \
     current.xml wordpress/native-blocks/revision-media-20260921.json output-dir
   ```

3. Применить результат только при совпадении исходной контрольной суммы:

   ```bash
   sudo wp eval-file wordpress/native-blocks/apply-revision-20260921.php \
     output-dir --path=/var/www/skysend --allow-root
   ```

После публикации обязательны проверка валидности блоков, HTTP-ответов, трёх
слайдов, блока партнёров и мобильной компоновки.
