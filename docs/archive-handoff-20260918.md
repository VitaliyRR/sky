# Пакет для переноса SkySend, 18.09.2026

Подготовлен полный функциональный пакет WordPress с действующей тестовой ВМ
31.129.98.28 для передачи администратору компании. В `gw1.isg.dev`, jail `www`,
ничего не устанавливалось и не изменялось. Перенос и DNS ещё предстоят.

- SHA-256: `820ebeb0accbcbb5050fb3a660c3c44da6d4653b3c7017aebeeb4e1977ddec1f`.

Указания для production robots предоставлены отдельно; DNS/HTTPS ещё не применены.

## Безопасность

Рабочий `wp-config.php`, SSH/root/DB/GitHub-пароли, серверные конфигурации Ubuntu,
неактивная прежняя тема, кеши, логи и приватный промежуточный дамп не включены.
Пароли **в копии** заменены случайными неизвестными значениями, сессии,
application passwords и ключи восстановления очищены. IndexNow-ключ исходной
ВМ очищен и автоматическая отправка отключена. Аккаунт `skysend_admin` сохранён;
на целевом сайте ему нужно задать новый пароль через WP-CLI.

Исходная БД и действующие пароли не менялись. Временные БД/DB-user удалены после
проверки, временный HTTP-сервер остановлен. Пакет содержит email и историю контента,
поэтому передаётся закрытым каналом и не хранится в публичном Git/FTP.
Локальный каталог `delivery/` исключён из Git и закрыт NTFS ACL.
