# «Партнерам» — единый слайд лендинга

По правке от 16.09.2026 блок партнёров больше не является каталогом ссылок.
Он оформлен как единый статичный слайд лендинга: шесть
симметричных изображений с названиями и краткими предложениями. Все партнёры
видны сразу, без дополнительных кнопок и переключателей.
По дополнительной правке от 16.09.2026 видимый заголовок «Партнерам» убран;
название пункта меню и доступное имя секции для скринридеров сохранены.

Ссылки «Подробнее» и кликабельные плитки убраны именно из блока партнёров.
Кнопки баннеров и ссылки других тематических блоков сохранены. XML-продукт
остаётся в разделе клиентского ПО, но больше не ссылается на удалённую страницу.
Фотография шлюзовиков на главной по-прежнему без надписи XML.

Отдельный шаблон страниц партнёров и обслуживавшие его маршруты/метаданные
удалены. Старые адреса agents, providers, suppliers, retailers, representatives,
gateways и advertisers перенаправляются HTTP 301 на главный слайд `/#participants`.
Неизвестные адреса не перенаправляются. В sitemap лендинга остаётся главная.
Удалённый шаблон доступен в истории Git и резервной копии на сервере.

Настольная высота слайда остаётся 600 px, как у других блоков. На узких экранах
шесть предложений располагаются в двух колонках, высота по содержимому.

## Публикация и проверка

Тема 3.2.0 опубликована 16.09.2026 на http://31.129.98.28/.
Сохранены прежняя тема, база данных и удалённый шаблон:
`/opt/skysend-backups/20260916-partners-slide/` (доступ только root).
Маршруты WordPress обновлены, кеш очищен, конфигурация Apache и синтаксис
всех восьми PHP-файлов опубликованной темы проверены без ошибок.

Проверки HTTP: главная — 200; все 14 вариантов семи старых адресов — 301
на `/#participants`; неизвестный адрес и удалённый шаблон — 404.
Внутренних ссылок на отдельные страницы партнёров нет. Sitemap содержит
только главную. Все 57 уникальных изображений доступны (200).
Nu HTML Validator: 0 ошибок.

Через навык браузера на изолированном макете проверены настольные размеры
1280 и 1024 px, а также мобильный экран 390 px; опубликованный слайд отдельно
проверен на настольном экране. На настольных экранах все семь блоков имеют высоту
600 px, на мобильном слайд партнёров адаптируется по содержимому.
Шесть изображений загружаются, в блоке партнёров нет ссылок и кнопок;
горизонтального переполнения и обрезанного текста не обнаружено.
