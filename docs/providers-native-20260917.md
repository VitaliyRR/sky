## Редактирование и резервная копия

Редактор: http://31.129.98.28/wp-admin/post.php?post=67&action=edit.
В обзоре документа секция содержит блок «Провайдеры — категории слева,
логотипы справа», внутри — «Категории провайдеров» и «Логотипы провайдеров».
Названия категорий и содержимое панелей редактируются штатным редактором.
Если страница была открыта до публикации, сначала сохраните нужные собственные
правки и обновите редактор, чтобы не перезаписать новую версию старой.

Закрытая резервная копия базы до и после правки и WXR страницы находится
на сервере в `/opt/skysend-backups/20260917-providers-native/`.
В Git не включены база, WXR с административными метаданными и пароли.

`providers-layout.mjs` — одноразовый инструмент подготовки штатных блоков,
не код сайта. Он принимает свежий WXR страницы; `apply-repair.php` проверяет
хеш исходной версии перед транзакционным обновлением через API WordPress.
Сохранённый manifest относится к уже опубликованной версии и не предназначен
для повторного применения поверх последующих правок в редакторе.
