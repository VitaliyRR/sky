## Структура и оформление

После баннера идут семь блоков в заданном порядке:

1. Партнёрам: шесть плиток с оригинальными фотографиями, названиями и краткими предложениями; без вводного заголовка и приклеенной плашки XML.
2. Уникальное ПО ALLVEND: устройства самообслуживания, заказ и оплата товаров/услуг, удалённое управление.
3. Высокая скорость обработки транзакций: кластер, распределение нагрузки и UNIX / FreeBSD.
4. Безопасность: защита серверных данных, каналов связи и терминального ПО.
5. Собственная операционная система FastSYS 5.
6. Клиентское ПО: ALLVEND, РМА Windows / Linux, РМА Android, XML-шлюз. Приложение FINGER и отдельное ПО для POS-терминалов не включены.
7. Провайдеры услуг: шесть категорий слева, логотипы справа; первая категория выбрана по умолчанию.

Высота каждого блока — 600 px при ширине окна от 980 px. На планшетах и телефонах высота адаптируется к содержимому, чтобы текст и элементы управления не обрезались. Используются единая сетка, синий цвет «Подробнее» и плоское оформление без теней.

Баннер содержит три отдельных дизайнерских изображения и названия: «Более 5 000 провайдеров услуг», «Лучшие финансовые условия», «Уникальное программное обеспечение». Мелкие надписи над заголовками и номера над полосками переключения убраны. Кнопки «Подробнее...» ведут к соответствующим блокам лендинга; изображение ALLVEND основано на официальной схеме типов устройств.

Футер по актуальному ТЗ: белый логотип SkySend слева, контакты компании и поддержки, шесть реальных загрузок ALLVEND — установочный образ и пять документов. Нижняя строка содержит «© 2006 - [текущий год] Группа компаний „Информ-Системы“» и текстовые ссылки через запятую: Telegram, YouTube, Facebook, Instagram, X (Twitter). Год подставляется WordPress автоматически. Адрес офиса не возвращён.

## Достоверность содержания

Использованы только сведения из старого SkySend и публичных материалов компании: кластер и синхронизация серверов, историческая разработка SkySend на FreeBSD, AES-XTS для серверных разделов, туннели IPSEC, цифровая подпись, шифрование образов ПО и данных, криптографическая привязка ПО к устройству, Linux и бинарные обновления FastSYS.

C++ как язык процессинга и отдельное шифрование ключей на терминалах не добавлены: публичного подтверждения не найдено, пользователь согласовал их исключение. Краткие предложения партнёрам пересказывают исходные возможности, без новых обещаний по доходности или SLA. Каталог провайдеров — выборка из исходного каталога, а не подтверждение текущей доступности каждой услуги.

## Выполненные проверки

- Изолированный макет проверен в браузере при ширинах 390, 768, 1024 и 1280 px:
  горизонтального переполнения и обрезки содержимого нет. На настольных размерах
  измеренная высота всех семи блоков — 600 px.
- Проверены три баннера, их кнопки и переключатели без цифр; все шесть категорий
  провайдеров, выбор первой по умолчанию, стрелки клавиатуры и Home; мобильное
  меню закрывается после выбора пункта.
- Опубликованная WordPress-версия повторно проверена на телефоне и рабочем столе:
  новые изображения загружаются, метаданные и ссылки навигации корректны.
- Главная и шесть страниц партнёров отвечают HTTP 200; старый advertisers
  перенаправляется 301 на retailers, неизвестный маршрут отвечает 404.
- Все 61 уникальный ресурс HTML и два файла шрифтов отвечают HTTP 200.
- PHP-синтаксис темы, JavaScript-синтаксис, разбор CSS и конфигурация Apache
  проходят проверку. После тестовых запросов новых ошибок PHP в журнале Apache нет.
- Сохранены title, description, canonical, Open Graph, robots meta и JSON-LD;
  у страниц партнёров уникальные метаданные и один H1.
- Повторная проверка HTML NuValidator: 0 ошибок, только информационные замечания
  WordPress и рекомендация по H1 внутри article. Robots и оба XML sitemap отвечают
  200, карта содержит ровно семь рабочих URL. Демостраницы отвечают 404.

## Найденные технические недоработки

1. Ссылки на четыре старые Joomla-страницы заменены официальными страницами ISG,
   чтобы они не ломались после переноса домена.
2. Запрещённый ARIA-атрибут на обычном абзаце футера исправлен: соцсети размещены
   в подписанном элементе навигации.
3. Robots.txt теперь ссылается на sitemap текущего сервера; установщик подставляет
   переданный SITE_URL, а не жёстко заданный старый домен.
4. Sitemap включает главную и все шесть собственных маршрутов партнёров.
   Архивы блога, пользователей и рубрик не включены в sitemap этого лендинга.
5. Стандартные «Привет, мир!» (ID 1) и «Пример страницы» (ID 2) переведены в
   черновики без удаления. До изменений сохранена резервная копия базы данных.
   При новой установке эти примеры также остаются неопубликованными.
