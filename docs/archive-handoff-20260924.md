Проверены контрольные суммы ядра WordPress 7.1.1 и трёх плагинов,
восстановление SQL в пустую БД, состав блоков, главная и служебные страницы
по HTTP, доступность локальных изображений и скриптов. Контрольная сумма ZIP
после копирования на локальный компьютер совпала.

Этот выпуск также содержит WP Super Cache 3.1.3. На ВМ разработки после
прогрева кеша анонимный запрос главной с loopback ускорился по TTFB примерно
с 0,22–0,26 с до 0,002–0,004 с при HTTP 200. После правок страницы, футера и
Global Styles кеш автоматически очищался; для админки, cookie и карты сайта
публичный кеш не применялся. Готовые кеш-файлы и drop-in **не входят в архив**:
на целевом сервере включить кеш только после замены URL и проверки прав по
отдельному разделу `README-INSTALL.md`. Без этого шага сайт работает, но
остаётся без ускорения повторных просмотров.

В пакете: новый плоский логотип в шапке и футере, favicon без старого
росчерка, исправленные иконки POS-терминала и шестерёнки, баннер с «Доход»
на мешочке и «+20%» справа сверху внутри изображения напольного терминала,
картинка «Шлюзовикам» с XML внутри фото, обновлённый текст FastSYS 5, без
предупреждения об архивных КП.
Раздел провайдеров содержит 279 примеров из [оригинального каталога
SkySend](https://skysend.ru/providers.php) в 10 категориях; в каждой категории
есть навигация стрелками и точками. Все новые изображения локальные и
оптимизированные; логотипы провайдеров на странице загружаются лениво.
Каталог исторический: действующий перечень услуг требует подтверждения.
Утверждение о работе устройств «на протяжении десятилетий» внесено по
предоставленной формулировке заказчика и отдельно официальными материалами
не подтверждено.

Изменения страницы 67, шапки 68, футера 69, Global Styles 66, favicon и
SEO-логотипа организации
хранятся в **БД**. Поэтому **обновление базы обязательно**: копирование только
файлов или только `uploads` не покажет новые секции, ссылки и favicon. Архив
содержит полный `database.sql`, но это **не SQL-патч**. Его нельзя импортировать
поверх существующей БД с таблицами. Безопасная установка: новый каталог,
новая пустая БД, импорт полного дампа, `wp search-replace` на фактический домен,
проверка, переключение vhost. Старые каталог и БД оставить для отката.

Пошаговые команды — [README-INSTALL](../deploy/wordpress/README-INSTALL.md),
тот же файл находится внутри ZIP. Если обновляется текущий стенд
`new.skysend.ru`, переменная `NEW_URL` должна быть `https://new.skysend.ru`;
для окончательного домена — его реальный HTTPS-адрес. Не использовать
`robots-production.txt` на промежуточном стенде.

Пакет содержит SQL и историю сайта, его передавать только закрытым каналом,
не выкладывать на GitHub, в FTP-листинг или webroot. Учётные пароли в копии
рандомизированы; после установки администратор задаёт новый пароль WordPress.
